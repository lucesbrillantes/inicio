# Luces Brillantes

Sitio web estático, mobile-first, para la atención personalizada de Erika Patricia Padrón Cerón y el catálogo de productos Ismerely.

## Publicar en GitHub Pages

1. Crea un repositorio nuevo en GitHub.
2. Sube todo el contenido de esta carpeta a la raíz del repositorio.
3. En GitHub entra a Settings > Pages.
4. Selecciona Deploy from a branch.
5. Elige `main` y la carpeta `/ (root)`.
6. Guarda y espera la URL de GitHub Pages.

No necesita Node, npm ni compilación: es HTML/CSS/JS puro.

## Antes de publicar

- Reemplaza el espacio de fotografía de Erika por su fotografía real.
- Revisa los nombres de productos, selecciones y recomendaciones con Erika.
- Revisa legalmente los textos de salud antes de usar publicidad pagada.
- Amplía `data.js` si quieres que el catálogo incluya todos los productos del PDF.
